# Trading Venues

Traderton supports four venues for agents to trade on. Each one is suited to
different needs — pick what fits your strategy.

New to the crypto ecosystem? Start with [Crypto Ecosystem](../crypto-ecosystem.md)
for an overview of blockchains, exchanges, and aggregators.

## Quick comparison

| Venue | What it does | Best for | Anonymity |
|---|---|---|---|
| [Hyperliquid](./hyperliquid.md) | Decentralized perpetual futures trading | Long/short directional bets, leverage | Yes (crypto wallet only) |
| [Bybit](./bybit.md) | Centralized exchange (spot + futures) | Wide asset selection, fiat on-ramp | No (KYC required) |
| [Jupiter](./jupiter.md) | DEX aggregator on Solana | Fast token swaps, best prices | Yes (crypto wallet only) |
| [1inch](./1inch.md) | DEX aggregator across EVM chains | Multi-chain swaps, best routes | Yes (crypto wallet only) |

## What should I choose?

- **You want leverage or to short** → Hyperliquid
- **You want to trade with fiat or need a wide selection of assets** → Bybit
- **You want the fastest and cheapest token swaps on Solana** → Jupiter
- **You trade across Ethereum, Arbitrum, or other EVM chains** → 1inch

Choose one during agent creation. You can always connect more later.

## Funding

Before an agent can trade, your wallets need to be funded. See
[Funding Your Wallets](./funding-wallets.md) for a step-by-step guide for each
venue.
